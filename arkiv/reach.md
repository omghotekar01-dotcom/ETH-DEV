# Target audience and reach

- **Who:** agent developers building with paid APIs, users testing agent autonomy, educators demonstrating spending guardrails, other apps that want to query public agent outcomes.
- **What they gain:** wallet-owned expiring coordination/outcome entities readable across apps without an app-specific database account.
- **Current users/active installations:** No verified user counts yet. This prototype is in research mode. Do not fabricate adoption metrics.
- **Next evidence:** invite actual hackathon participants to try RIFT, measure use with consent, retain session-level feedback without collecting personal secrets.
